# DayTag Brand Spec

## 来源与范围

DayTag 是本次从零建立的新产品，没有既存官网、Logo、VI、字体规范或 UI Kit。设计不引用第三方品牌资产，也不需要图库摄影。原型中的图标只承担“新增、返回、日期、添加桌面”等功能，不使用装饰性 Emoji。

## 品牌核心

- 产品定位：把重要日子留在身边，而不是制造又一个任务清单。
- 气质关键词：温暖、克制、清楚、有触感、不过度催促。
- 核心信息：目标日未来时倒数，当天成为“今天”，过去后自然转为“已经多少天”。
- 使用距离：手机近距阅读，以一眼读清大数字为第一优先级。
- 视觉母题：一天的刻度。可由日历纸、晨间留白或实体日期吊牌承载。

## 资产

### Logo

- 状态：待最终方向确定后创建原创自适应图标。
- 原则：抽象日期标记或标签形态，不使用通用渐变色球、字母渐变或生成式 AI 图标。
- 文件目标：Android adaptive icon foreground / background / monochrome。

### 产品图与摄影

- 当前不需要。
- UI 本身的数字、日期和布局是内容，不用装饰性 stock photo 填充页面。

### 色彩

三个方向均只使用一个有温度的底色、深色正文和一个强调色。

- 纸上日历：羊皮纸 `#F4EBDD`、墨色 `#292621`、陶土橙 `#B64F2E`
- 暖雾留白：暖雾 `#F6F1E8`、深褐 `#312C26`、鼠尾草绿 `#586B54`
- 日期吊牌：奶油黄 `#F0E4CC`、深可可 `#2D211A`、朱砂红 `#A6442B`

### 字体

- 数字与展示：优先衬线拉丁数字，强调“日期被记录”的时间感。
- 中文正文：系统无衬线或可读的思源黑体风格，确保 Android 中文清晰。
- 不将 Inter、Roboto 或系统字体作为唯一品牌表达。

## 禁用项

- 紫色科技渐变、霓虹光晕、无意义的数据装饰。
- 每一行都配图标、圆角卡片加左侧色条、Emoji 当图标。
- 用模糊 SVG 手绘替代真实产品内容。
- 为了“极简”牺牲可读性、触控面积或正文对比度。

## 可访问性

- 正文对比度至少 4.5:1。
- 触控目标至少 48dp。
- 大数字与单位必须保持语义关联，并提供完整读屏描述。
- 颜色不是区分事件状态的唯一手段，文案始终明确显示“还有 / 今天 / 已经”。
